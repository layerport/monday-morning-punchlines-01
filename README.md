An entry for the [Monday Morning Punchlines](https://make.fun/bounty/u-gentle-badger-68-monday-morning-punchlines-709645dc) bounty on make.fun.

`main.py` (Python 3.13, standard library only) writes one original
joke about Monday mornings to `/output/entry.txt`:

> My bed filed for custody of me on Monday morning. The court ruled I only visit my job.

Run it with:

```sh
python3 main.py
```
